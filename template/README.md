# {{PROJECT_NAME}}

A modern React + TypeScript + Vite frontend app — generated by [`create-frontstack`](https://www.npmjs.com/package/create-frontstack).

## Stack

- **React 19 + TypeScript 6 + Vite 8** (Tailwind v4, CSS-first)
- **TanStack Router** (file-based, type-safe routing) + **TanStack Query** (server state)
- **Zustand** (client/UI state)
- **shadcn/ui** (v4) + **lucide-react** icons
- **Vitest + happy-dom** (unit/component) and **Playwright** (E2E)
- **ESLint** (flat, type-aware) + **Prettier**
- **Docker** — multi-stage production image (nginx) + dev image + compose
- **Agent skills** (`skills/`) and **MCP** (`.mcp.json`)

## Requirements

- Node.js **>= 22.12** (`.nvmrc` pins 26). pnpm is enabled via corepack.

## Getting started

```sh
pnpm install
npx playwright install   # only needed for E2E + playwright/chrome-devtools MCP
pnpm dev
```

## Scripts

| Script                                                                  | What it does                                              |
| ----------------------------------------------------------------------- | --------------------------------------------------------- |
| `pnpm dev`                                                              | Start the Vite dev server                                 |
| `pnpm build`                                                            | Generate route tree, typecheck, and bundle for production |
| `pnpm typecheck`                                                        | Generate route tree and run `tsc --noEmit`                |
| `pnpm lint` / `pnpm lint:fix`                                           | ESLint (type-aware)                                       |
| `pnpm format` / `pnpm format:check`                                     | Prettier                                                  |
| `pnpm test` / `pnpm test:watch` / `pnpm test:ui` / `pnpm test:coverage` | Vitest (unit/component)                                   |
| `pnpm test:e2e` / `pnpm test:e2e:ui`                                    | Playwright (E2E)                                          |
| `pnpm check`                                                            | typecheck + lint + test                                   |
| `pnpm ui:add`                                                           | Add a shadcn/ui component (`pnpm ui:add button`)          |

## Project layout

```
src/
├── main.tsx              # Router + <AppProviders><RouterProvider/></AppProviders>
├── providers.tsx         # QueryClientProvider + devtools
├── routes/               # File-based routes (TanStack Router) — __root, index, about
├── routeTree.gen.ts      # Generated (gitignored) — do not edit by hand
├── features/<name>/      # Feature modules: api.ts + use-*.ts hooks
├── stores/               # Zustand stores (client/UI state only)
├── components/ui/        # shadcn/ui components
├── lib/                  # cn(), query-client
└── test/setup.ts         # jest-dom matchers + cleanup
e2e/                      # Playwright specs
```

### State management

- **Server-state** (API data, caching, invalidation) → **TanStack Query**. Fetch functions in `features/<name>/api.ts`, hooks in `features/<name>/use-*.ts`.
- **Client/UI state** (theme, sidebar, flags) → **Zustand** stores in `src/stores/`.
- Never duplicate server-state into Zustand — Query is the source of truth for backend data.
