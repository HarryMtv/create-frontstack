# {{PROJECT_NAME}}

A modern React + TypeScript frontend app — generated by [`create-frontstack`](https://www.npmjs.com/package/create-frontstack).

## Stack

- **React 19 + TypeScript + Vite 8** (Tailwind v4, CSS-first)
- **Vite+** (`vp`) — one toolchain for dev, build, tests, type checks, linting and formatting
- **TanStack Router** (file-based, type-safe routing) + **TanStack Query** (server state)
- **Zustand** (client/UI state)
- **shadcn/ui** (v4) + **lucide-react** icons
- **Vitest + happy-dom** (unit/component) and **Playwright** (E2E)
- **Oxlint** (type-aware) + **Oxfmt**
- **Docker** — multi-stage production image (nginx) + dev image + compose
- **Agent skills** (`skills/`) and **MCP** (`.mcp.json`)

## Requirements

- Node.js **>= 22.18** (`.nvmrc` pins 26) — `vp` runs on Node.
- **Bun 1.3.14** — the package manager (`packageManager` in `package.json`).

## Getting started

```sh
bun install
bunx playwright install   # only needed for E2E + playwright/chrome-devtools MCP
bun run dev
```

## Scripts

| Script                                                                              | What it does                                              |
| ----------------------------------------------------------------------------------- | --------------------------------------------------------- |
| `bun run dev`                                                                       | Start the Vite dev server                                 |
| `bun run build`                                                                     | Generate route tree, typecheck, and bundle for production |
| `bun run typecheck`                                                                 | Generate route tree and run type checks (`vp check`)      |
| `bun run lint` / `bun run lint:fix`                                                 | Oxlint (type-aware)                                       |
| `bun run format` / `bun run format:check`                                           | Oxfmt                                                     |
| `bun run test` / `bun run test:watch` / `bun run test:ui` / `bun run test:coverage` | Vitest (unit/component)                                   |
| `bun run test:e2e` / `bun run test:e2e:ui`                                          | Playwright (E2E)                                          |
| `bun run check`                                                                     | format + lint + typecheck + test                          |
| `bun run ui:add`                                                                    | Add a shadcn/ui component (`bun run ui:add button`)       |

Prefer the built-ins: `bunx vp dev`, `bunx vp test`, `bunx vp lint`, `bunx vp fmt` and
`bunx vp build` run the tools directly. `bun run <script>` runs the package scripts above.

## Project layout

```
src/
├── main.tsx              # Router + <AppProviders><RouterProvider/></AppProviders>
├── providers.tsx         # QueryClientProvider + devtools
├── routes/               # File-based routes (TanStack Router) — __root, index, about
├── routeTree.gen.ts      # Generated (gitignored) — do not edit by hand
├── features/<name>/      # Feature modules: api.ts + use-*.ts hooks
├── stores/               # Zustand stores (client/UI state only)
├── components/ui/        # shadcn/ui components
├── lib/                  # cn(), query-client
└── test/setup.ts         # jest-dom matchers + cleanup
e2e/                      # Playwright specs
```

### State management

- **Server-state** (API data, caching, invalidation) → **TanStack Query**. Fetch functions in `features/<name>/api.ts`, hooks in `features/<name>/use-*.ts`.
- **Client/UI state** (theme, sidebar, flags) → **Zustand** stores in `src/stores/`.
- Never duplicate server-state into Zustand — Query is the source of truth for backend data.
